# Skill 维护源

knowledge-video 当前版本 2.5.0，默认适配 Remotion 工程 0.1.0。旧 Canvas 工程 0.3.0 通过显式 --root 或 KNOWLEDGE_VIDEO_ENGINE 选择，并使用独立的 legacy 参考说明。

定位脚本只读取文件，不安装或修改工程；未知版本、不完整目录和错误显式路径均失败，不通过替换版本号绕过检查。当前仓库中的工程可以从维护源相对位置发现，迁移到其他电脑时也可显式设置路径。

SKILL.md 保留内容驱动、连续配乐、用途与音色分离、过程音按需、人工听感与自动检查分离等原则。命令和配置的完整定义以工程文档为准。

后续先修改这里的维护源，验证后同步本机安装副本，避免维护两套独立规则。
