## 人工判断与限制

已查看握手、半关闭、TIME_WAIT 等关键截图。自动布局检查不等于整片审美验收；没有宣称人工试听通过。audio-demo 是程序生成的技术配乐和短音样本，声音方案仍需根据真实内容选择和试听。

TCP 的字幕时间与协议状态沿用旧案例并检查；画面使用新组件重做，并非旧片像素复刻。原配乐没有打包进迁移项目。

当前提供三类场景、两套配色；适用横屏二维、单轨中文字幕、无旁白和最多 600 秒的内存混音。没有自动节拍分析、调性匹配、AI 作曲、云渲染或通用一键分镜。跨平台部署、超长视频和新场景类型需另行验证。

GitHub Actions 配置已提供，但本报告不声称云端工作流已经执行。
