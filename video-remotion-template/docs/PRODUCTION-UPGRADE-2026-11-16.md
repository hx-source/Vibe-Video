# 工程与制作规则更新 · 2026-11-16

本轮按依赖与快照、参数化组件、渲染检查的顺序完善工程；制作规则升至2.5.0，补充阅读与衔接、声音设计。当前交付版本仍是landscape-live-final-v1，52秒、1920×1080、30fps、漫画风格、02背景音乐。本轮没有替换成片或切换当前版本。

## 工程变化

- snapshot冻结间接场景依赖、JSON参数、启用的音频素材、字体、编译配置、包清单与锁文件，并保留输入原字节及独立画面、混音执行包。按哈希去重，损坏检测与实时源变化分开报告。
- revise的JSON补丁接入实际构建；新代码来源显式登记。预期公共依赖变化通过精确dependencyUpdates进入新修订，旧哈希与快照不改写。
- 提取LabelTransition与PriceComparison，分别复用标签身份转换和价格/判断对比。52秒项目适配源位于projects/thinking-anchors/scenes，旧批准源保持。独立6秒价格对比演示无音轨，不能当成用户配乐成片。
- render按整条时钟处理画面与声音，默认带修改前后文，输出到新目录，自动检查并登记视频与对应分轨。check复核冻结包、媒体哈希、规格、完整解码及分轨；status、activate也检查登记分轨变化。
- 未改范围采用边界抽样，记录DOM与像素差异；修改及上下文范围逐帧检查文字边界。浏览器抗锯齿小差异的放行条件和实际证据保存在checks.json，不能当成全部未修改帧的证明。

操作和格式见 [统一制作流程](PRODUCTION-WORKFLOW.md)。旧入口继续可用；未接入参数化适配器的场景，仍需原渲染入口后登记媒体。

## 制作规则变化

- [阅读与衔接](../../skills/knowledge-video/references/reading-transitions.md)：从稳定可读开始考虑停留，处理动作与文字竞争，保持商品和价格的前后关联，让下一段回答上一段的问题，局部检查保留完整信息点。
- [声音设计](../../skills/knowledge-video/references/sound.md)：区分启动、意义改变和落定；按素材可听起点对齐，判断逐个提示还是整体提示，处理重复、混响、截断及持续声问题，先听局部混音再用分轨排查。
- 不固定每镜秒数、阅读速度或某种通用音色，不增加重复审批，保留已认可配乐与听感记录。技术通过不能代填观看、试听或认可。

项目维护源与已安装副本均为2.5.0，11个文件逐一哈希一致。安装前备份保存在仓库.cache/skill-backup-before-2.5.0-20261116-124637，旧2.4.0备份也保留。
